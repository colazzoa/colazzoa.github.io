Questa pagina mostra i file del tuo Google Drive dopo che accedi con il tuo account Google. I dati restano privati: nulla viene salvato sul sito, tutto avviene nel tuo browser tramite le API ufficiali di Google.

1. Configurazione (una sola volta)

Inserisci il tuo OAuth Client ID e la tua API Key creati sulla Google Cloud Console. Vengono salvati solo nel tuo browser (localStorage), non nel sito.

Come ottenere Client ID e API Key
  1. Vai su Google Cloud Console e crea (o seleziona) un progetto.
  2. In APIs & Services → Library abilita la Google Drive API.
  3. In APIs & Services → Credentials crea una API Key.
  4. Sempre in Credentials crea un OAuth client ID di tipo Web application. In Authorized JavaScript origins aggiungi l'URL di questo sito (es. https://…).
  5. Configura la OAuth consent screen e aggiungi il tuo indirizzo Google come Test user (se l'app è in modalità Testing).
2. Accedi e sfoglia
Configura le credenziali qui sopra per iniziare.
